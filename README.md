# Borç Pusulası

Kişisel borç ve gider takibi için iPhone'a kurulan web uygulaması (PWA).

- Kredi kartları, krediler, kişilere dolar / gram altın borçları (güncel TL karşılığı ve kur etkisi)
- İş yeri ve kişisel sabit giderler; kartla ödenen gider kartın borcuna eklenir
- Yaklaşan 30 günlük ödemeler, aylık otomatik borç kaydı, borç bitiş tahmini
- Veriler yalnızca cihazda (IndexedDB). Ayarlar → Yedek al ile dışa aktarılır.

Adres: https://guraymarhan.github.io/finans-uygulamasi/

## Geliştirme
```
npm install
npm run dev
```
`main` dalına her gönderimde GitHub Actions uygulamayı GitHub Pages'e yayınlar.
